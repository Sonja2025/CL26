# Rakazo plugins

| Plugin | What it does |
|---|---|
| [pmsuite-spikesz](pmsuite-spikesz/) | Connects Rakazo bots to PM Suite (Spikesz workspace): CRM, finance, projects and read-only connections. |

This repo holds only connection URLs and skill instructions. No API keys or other secrets belong here; keys are entered in Rakazo under **Manage MCP servers → Advanced → Access token**.

Install in Rakazo: **Integrations → + → From GitHub**, then paste the plugin folder URL, e.g. `https://github.com/Sonja2025/CL26/tree/main/pmsuite-spikesz`.
